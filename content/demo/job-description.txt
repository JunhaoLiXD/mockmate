Software Engineer (Entry Level), AI Customer Experience
Fernbrook Retail Group (fictional) | Atlanta, GA (Hybrid) | Full-time

ABOUT FERNBROOK
Fernbrook Retail Group runs 300 home-goods stores and an online shop. Our AI
Customer Experience team builds assistants that help customers and store staff:
answering product questions, guiding returns, and coaching new associates. These
tools talk to real customers every day, so they have to be accurate, safe with
personal data, and affordable to run at scale.

ABOUT THE TEAM
We are a 10-person team of engineers, a product manager, and a data analyst. We
work closely with store operations, legal, and customer support, and we ship to
production every week.

WHAT YOU'LL DO
- Build full-stack features in TypeScript with React and Next.js, including
  server routes that call large language model APIs.
- Add real-time features, such as voice or streaming chat, and handle the
  failure cases that come with them: dropped connections, slow responses, and
  users who interrupt.
- Design structured outputs and validation so model responses can be checked
  before customers see them.
- Protect customer data: keep secrets on the server, limit what is logged, and
  treat user input as untrusted.
- Control cost and abuse with input limits, rate limits, and kill switches.
- Measure whether an AI feature actually helps, and explain the results and
  trade-offs to non-technical partners in operations and support.

BASIC QUALIFICATIONS
- Bachelor's degree in Computer Science or a related field (new graduates
  welcome).
- Strong programming skills in TypeScript or JavaScript.
- Experience building web applications with React.
- Experience building and calling REST APIs.
- Understanding of core data structures, algorithms, and software design.
- Experience with Git.

PREFERRED QUALIFICATIONS
- Experience with Next.js or another server-rendered React framework.
- Experience building with large language model APIs, including prompt design
  and structured outputs.
- Experience with real-time web technologies such as WebRTC or WebSockets.
- Experience deploying an application to a cloud platform.
- Experience with input validation and schema libraries (for example zod).
- Ability to explain technical risk and cost to people without a technical
  background.

WHAT WE VALUE
- Reliability over cleverness: features that fail safely and predictably.
- Honest measurement: knowing when an AI feature is wrong, and why.
- Clear thinking about trade-offs between quality, speed, cost, and privacy.
- Respect for customers' time and data.
